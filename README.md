# Student-Performance-Analysis-
# 📊 Student Performance Analysis Based on Demographic and Educational Factors

## 📖 Project Overview

This project explores how demographic and educational factors influence student academic performance. Using Python and Jupyter Notebook, the analysis investigates relationships between gender, parental level of education, lunch type, test preparation course, and student scores in mathematics, reading, and writing.

The project follows a complete data analysis workflow, including data exploration, cleaning, statistical analysis, visualization, and interpretation of results.

---

## 🎯 Project Goal

The goal of this project is to analyse student academic performance and identify the factors that influence mathematics, reading, and writing scores. By applying data analysis techniques, the project aims to discover meaningful patterns and relationships that can support better educational decision-making.

---

## ❓ Research Questions

- Does gender affect student performance?
- Does parental level of education influence exam scores?
- Does completing the test preparation course improve academic performance?
- Is there a relationship between lunch type and student achievement?
- Which subject has the highest average score?
- How strongly are mathematics, reading, and writing scores related?

---

## 📂 Dataset

**Dataset:** `exams.xlsx`

The dataset contains **1,000 student records** and **8 variables**.

### Features

| Column | Description |
|---------|-------------|
| gender | Student gender |
| race/ethnicity | Student group |
| parental level of education | Parents' education level |
| lunch | Lunch type |
| test preparation course | Completed or not completed |
| math score | Mathematics exam score |
| reading score | Reading exam score |
| writing score | Writing exam score |
